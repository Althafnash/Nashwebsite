How dose cloud computing works

The cloud computing is basically divide into two frontend and backend

The frontend help users access the data stored on the cloud by using an application or web browser , Front end defines the user experience as well

The backend consists of data , servers and everything that is needed to responded to all the request made to the front end.

For example data is stored in the backend while graphs can be displayed on the front end

Middleware is a software platform acts as a bridge in between two or more application or devices , middleware are usually not used by the end users directly , a vital component that is required in cloud computing

Virtualization in cloud computing

Virtualization is creation of a virtual version of an entity such as a desktop , an operating system or even network resources

It is a technique that allows us to share a single physical instance over multiple teams , costumers and even organizations

One computer can run multiple operating systems such as Linux , windows and more at a time

These operation system are called guest operating systems

With virtualization we can have a software deployed across many hardware entities that get segmented into sperate elements called virtual machines

Commonly shared hardware entitles are processes , memory units and storage blocks

Thousands of companies around the globe use virtualization to make effective use of resources and to help drive their cloud computing requirements

Cloud users can only purchase the necessary resources and expand as and when required

Important Virtualization Terminologies

Important Virtualization terminologies which are Virtual Machine , Virtualization Tool , Containerization ,virtual Network , Hypervisor

A Virtual machine is often just a computer file that is called as an image , This image emulates the behaviour of actual computer, Installing Linux on windows

A Virtualization tool is a piece of software that is part of a larger application

This tool in assisting development operation of the virtualization application on a required computer device

Containers are considered to be lightweight virtual machine that are running a same operating system

They contain all the elements required to run a piece of code or application in any environment

A virtual network is a building block of virtualization as it helps in enabling communication between multiple virtual machines servers computers and other devices

Virtual network are commonly used by individuals and enterprises alike

Hypervisor is a software that has a ability to create , run and monitor virtual machines

Hypervisor make virtualization possible as it helps in translation of requests between virtual and physical resources

Hypervisor is also called as VMM or a virtual machine monitor
